# T36 quick glossary

| Term | Plain-language meaning |
|---|---|
| **Agent** | One model instance participating in the evaluation. |
| **Fleet** | Group of participating agents in a configured experiment. |
| **MC** | *Mémoire collective*: proposed shared memory restricted to evidence-linked, explicitly admitted facts. |
| **Lineage fence** | Pre-write check that every claim has required identifiers and provenance. Missing lineage blocks consolidation. |
| **Pin** | Explicitly identified, evidence-linked fact allowed into a restricted shared store; not a free-form model opinion. |
| **T↑** | More rounds of deliberation. More rounds are not automatically more reliable. |
| **GREEN / YELLOW / RED** | Evidence review statuses: supported under defined checks / unresolved / rejected. Labels require criteria; they are not truth probabilities. |
| **VALIDATED** | A claim that passed its specified external validation rule; not merely agent consensus. Domain and adjudicator must be named. |
| **External adjudication** | Compare a decision recorded before outcomes with evidence produced outside the deciding agents. |
| **"Market + human"** | Two **different roles**, not a universal voting panel: a later crypto-market outcome supplied direction labels in specific experiments; human oversight handled risk and authorization. Neither alone establishes universal truth. |
| **Native disagreement / split** | Distinct directional judgments among members of a fleet on a single recorded step. Not a guarantee of healthy reasoning. |
| **Echo / false consensus** | Observed or hypothesized coordinated agreement without reliable external grounding; requires an explicit operational criterion before measurement. |
| **Receipt** | Data, code, expected output, provenance, and limitations sufficient to check a bounded claim. |
| **N_crit = NULL** | No defensible critical reference-population size found under the frozen Gate 8.4 rule; not a universal impossibility finding. |

These short definitions are explanatory, not replacements for the series' formal measurement rules.
