# X Series — Part 2: The Instruments

Part 2 introduces three observables used to describe the **shape of a multi-agent deliberation**:

- **λ∥ (lambda longitudinal)** — temporal change within an agent across reasoning rounds.
- **λ⊥ (lambda transverse)** — divergence among agents in a shared representation space.
- **τ (tau)** — an engagement / influence proxy comparing an agent's current representation with peers' prior context.

These are **process measurements, not truth scores**.

They can describe whether agents are stabilizing, separating, converging, or appearing to respond to one another. They do not, by themselves, establish whether a claim is factually correct or whether a consensus will be externally vindicated.

That separation is intentional. Part 1 defines the external-adjudication logic. Part 2 defines the instruments used to characterize what happens *inside* the deliberation before that external verdict is known.

## Reading rule

A system can display orderly dynamics and still be wrong.

**measured deliberative form ≠ epistemic validity**

Whether any of these internal observables contain information about later external validity is an empirical question addressed by the subsequent experiments.
