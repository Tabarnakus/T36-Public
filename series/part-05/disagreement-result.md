# Disagreement result

Across the six paired real-market windows, the heterogeneous fleet produced more native split structure than the homogeneous fleet in **all six windows**.

| Quantity | Result |
|---|---:|
| Paired market windows | **6** |
| Windows where heterogeneous > homogeneous disagreement | **6 / 6** |
| Mean disagreement difference | **+14.6 percentage points** |

The direction of the effect is therefore consistent across every paired window in this small sample.

## Interpretation

This supports the claim that changing the tested fleet composition changes the **form of deliberation**, specifically the rate at which the agents natively disagree under the same market context.

The result does not by itself establish why the effect occurs. Possible contributors include model-family diversity, training lineage, capability differences, response priors, and interaction style.

The associated paired test is documented in [`statistics.md`](./statistics.md).
