# Consensus-following accuracy

External validity is adjudicated by the realized market outcome at fixed horizons.

For each fleet, the table below reports the accuracy obtained by following the fleet consensus.

| Fleet | H = 1 | H = 3 | H = 5 |
|---|---:|---:|---:|
| Homogeneous | **47.9%** (n = 1,145) | **46.7%** (n = 1,124) | **45.1%** (n = 1,103) |
| Heterogeneous | **48.5%** (n = 196) | **43.5%** (n = 186) | **37.5%** (n = 176) |

## Result

No cell exceeds 50%.

The heterogeneous fleet changes the deliberative structure substantially, but its consensus-following accuracy does not improve at any tested horizon.

The result should be read narrowly:

> **More internal disagreement did not produce more externally reliable agreement in these data.**

This table describes consensus-following performance. It does not claim that every individual agent, every possible aggregation rule, or every other domain must behave the same way.
