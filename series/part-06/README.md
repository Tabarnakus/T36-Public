# X Series — Part 6: Form–Validity Dissociation

Part 5 recorded a **six-window paired OLD/NEW roster contrast** in native disagreement. Part 6 asks a separate question about external outcomes: does changed deliberative form correspond to better consensus-following performance?

The published aggregated outcome cohorts show **no measured improvement**. Across the reported H=1, H=3 and H=5 horizons, consensus-following accuracies were below 50% for **both** named rosters. **These outcome cohorts have different denominators from the six matched replay windows**, so the measures should not be treated as the same paired statistical sample.
