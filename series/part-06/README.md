# X Series — Part 6: Form–Validity Dissociation

Part 5 showed that changing fleet composition changes deliberative form: in the matched replay, the heterogeneous fleet produced more native disagreement.

Part 6 asks the next question:

> If deliberative form changes, does external validity improve with it?

This evidence packet documents the consensus-following result across the homogeneous and heterogeneous fleets at the three fixed adjudication horizons.

## Reading rule

Changing the shape of deliberation is not the same thing as improving the external validity of the resulting consensus.

In the tested fleets, **consensus-following never exceeded chance at H = 1, 3, or 5**.

Part 6 therefore separates two questions that are easy to conflate:

1. Can fleet composition change deliberative form? **Yes, in the tested replay.**
2. Does that change make consensus more externally reliable? **Not in these data.**

Later controller questions are intentionally not disclosed here.
