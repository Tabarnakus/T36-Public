# Regime accessibility

Part 4 examines whether the tested homogeneous open-weight fleet actually occupies the independently specified healthy deliberative regime.

Here, **healthy** is a dynamical label, not an epistemic one.

It does not mean:

- correct;
- truthful;
- externally validated;
- free of hallucination.

It refers to a candidate operating region intended to represent deliberation that is neither immediate collapse into agreement nor uncontrolled separation.

## Observational test

The real-fleet corpus was examined in the measured state space rather than assuming that the synthetic calibration transferred automatically.

For the pooled real-fleet analysis:

- specimens/steps: **n = 1,009**;
- engagement coverage: **99.2%**;
- measured state variables were standardized before the separability calculation;
- split-structured vs echo-structured steps were compared using silhouette;
- uncertainty used **600 bootstrap resamples clustered by run**.

The empirical question was whether the region occupied by this fleet showed practically separable structure under the same **0.15** criterion used elsewhere in the work.

The result is reported separately in [`separability-result.md`](./separability-result.md).
