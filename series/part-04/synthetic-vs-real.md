# Synthetic calibration vs real-fleet observation

The T36 regime model was first explored in controlled synthetic simulations designed to populate distinct regions of a dynamical state space.

That synthetic work is useful for constructing hypotheses, stress-testing instruments, and defining candidate regions. It does **not** establish that real LLM fleets occupy the same regions or preserve the same separability.

## Transfer question

The real-fleet test therefore asks:

> Does the observed homogeneous LLM fleet occupy a region with empirically separable deliberative structure under the same measurement framework?

This is a transfer test, not a post-hoc rescaling exercise.

## Why affine rescue is insufficient

Changing the origin, scale, or reference distance can move numerical coordinates. It cannot by itself create empirical class separation where the observed labels substantially overlap.

For that reason, the relevant question is not whether a synthetic diagram can be visually aligned to the real data after the fact. The relevant question is whether the real observations themselves contain separable structure under an independently specified criterion.

## Boundary

The synthetic regime model remains an effective/descriptive model. Its calibrated regions and thresholds are not asserted to be universal physical laws of LLM deliberation.
