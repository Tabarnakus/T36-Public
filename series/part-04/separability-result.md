# Separability result

The pooled real-fleet analysis produced:

| Quantity | Result |
|---|---:|
| Corpus size | 1,009 steps |
| Engagement coverage | 99.2% |
| Silhouette | **0.005** |
| 95% bootstrap interval | **[0.001, 0.012]** |
| Pre-specified practical separation criterion | **0.15** |
| Macro-state-label silhouette | **-0.010** |

The observed silhouette is therefore far below the practical separation criterion.

A rank test on lambda-perpendicular can still return statistical detectability at this sample size, but detectability of a distributional difference is not the same as practically separable regime geometry.

This distinction matters:

> **Detectable ≠ separable.**

The result does not support treating the occupied real-fleet band as the same cleanly separated regime structure suggested by the synthetic calibration.

It also means that simply moving a numerical boundary after observing the data would not validate the original regime interpretation.
