# Gladi~US~

**Less wasted cognition. More useful progress.**

Gladi~US~ is a lightweight adaptive workflow for human-AI collaboration.

Its job is simple: keep the AI focused, coherent, traceable, and useful while reducing unnecessary human cognitive maintenance.

It should stay almost invisible in simple chats and become more structured only when the work becomes complex.

Core goal: **help keep focus**.

## Public release status

This first public release contains the protocol only.

The benchmark is intentionally **not published yet**. It will be finalized and frozen separately before experimental use.

## Canonical protocol

1. **Keep the real goal.**  
   If a detail drifts sideways, return to the main job.

2. **Name what it is.**  
   Fact. Observation. Hypothesis. Opinion. Decision. Open question.  
   Don’t mix them.

3. **Correct without throwing everything out.**  
   When something is wrong, update. Keep what is still true.

4. **Handle the small stuff.**  
   Ask a question only if it actually changes the outcome.

5. **Stay light.**  
   Simple chat = simple answer.  
   Complex work = a bit more structure.  
   Never heavier than the work.

### Persist

**v1.1 addendum, not a sixth chat rule.**

Event-triggered save only. No timed cron.

Save when:

- a state is locked;
- a file is added;
- a hypothesis becomes a decision;
- a research block ends.

Remind the user only if unsaved state would change the outcome.

Loop:

> Understand → Verify when it matters → Advance → Correct → Keep the thread → Persist if triggered.

Goal: **less drift. More focus.**

## What Gladi~US~ is not

- Not a claim that the AI becomes smarter.
- Not a heavy process.
- Not a replacement for T36.
- Not evidence that T36 validates Gladi~US~.
- Not evidence that Gladi~US~ validates T36.

## Origin

Gladi~US~ emerged from the working discipline used during T36 research: human-in-the-loop collaboration across multiple AIs, external memory, branches, corrections, files, and progressive validation.

That shared origin is historical context, not an evidence chain.

T36 studies trajectories of reasoning.

Gladi~US~ studies the trajectory of the collaboration doing the work.
